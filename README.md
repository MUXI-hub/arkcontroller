# ArkController — 《明日方舟》卫戍协议 Xbox 手柄全流程操控系统

**ArkController** 是一套专为《明日方舟》**「卫戍协议」**（含常驻「规程」及「盟约」系列单人/多人联机玩法）打造的 **零内存注入、纯键鼠模拟、高响应手感** Xbox 手柄外部操控工具。

系统采用 **「局外纯模拟自由鼠标 + 局内 16:9 智能槽位吸附与 4 点透视棋盘」** 混合架构，结合 **棋盘原地回环转向与两段式定朝向状态机**、**右侧策略头像跨区拖拽**、**回合确认弹窗自适应导航** 以及 **PySide6 PRTS 风格透明鼠标穿透悬浮 HUD**，让你全程使用 Xbox 手柄即可零门槛、高精度完成卫戍协议全部对局操作。

---

## 核心特性

- **零注入安全架构**：全程仅调用 Windows 标准 `SendInput` 键鼠合成与桌面/窗口截图 API，**绝不读取或修改游戏进程内存，绝不注入任何 DLL**；游戏切至后台时自动静默挂起，杜绝误操作桌面。
- **局外免维护自由鼠标 × 局内五大核心阶段全覆写**：
  - **局外与设置界面（`UNKNOWN_FREE_CURSOR`）**：彻底移除易受版本变动影响的局外菜单预设节点，依托局内双锚点防误判门禁确保启动及任意局外画面（主界面、活动页、战前编队、干员列表与结算页）100% 稳定处于自由鼠标模式；自动无损对齐窗口内物理鼠标指针，左摇杆平滑驱动三次方双速曲线模拟光标（`A` 单击、`RT+A` 双击、`B` 发送 `Esc`、`RS` 滚轮滚动）；
  - **局内五阶段智能切换（三套卫戍主题 & 全置灰全适配）**：全面适配**闭合紫粉电玩风 / 乌萨斯复古辉光管风 / 罗德岛战术青绿风**三套卫戍协议主题，零模板实时识别休整期（`BATTLE_PREP`，兼容联机 `LOADING...` 无准备按钮态、刷新/冻结双按钮同时变灰以及三主题全按钮置灰态）、单人 `1x2` 二选一 / `1x3` 三选一与多人 `2x3` 六选一决策弹窗（`MODAL_CHOICE`，兼容 1~5 张已被队友选走的浅灰卡）、回合结束与局内 `ESC` 暂时离开确认弹窗（`MODAL_CONFIRM`）、自动作战期（`BATTLE_COMBAT`，含右下费用栏 `◆ C` 直判与多人队友抽屉零误判）与过渡/自由鼠标态（`UNKNOWN_FREE_CURSOR`）。
- **混合智能导航**：局内默认左摇杆（`LS` 推动）可直接代替十字键（`D-Pad`）配合肩键（`LB`/`RB`）在商店、10 格整备区、5 格装备栏、4x7 透视棋盘（支持 Boss 战右侧分配自动水平镜像切换）、顶部放大镜与 `1~7` 居中对称 / `>7` 溢出可左右拖拽滑动且任意滚动相位动态吸附盟约栏、左侧联机队友头像栏、左下 `2x3` 交流表情面板及右侧策略头像间高速跳格；任意时刻按下 **`LS`** 即可切换为自由虚拟鼠标（再按 `LS` 或方向键无缝恢复吸附）。
- **自走棋 × 塔防专属优化**：
  - **商店防误触两下 `A` 买牌 & `RT+A` 查详情**：商店区第 1 下按 `A` 本地预选（不发单击防详情抢焦点），2 秒内再按一次 `A` 双击购买；按 **`RT+A`** 查看该商店干员详情（屏蔽误卖/误撤，按 `B` 点击左上延迟安全区退出并精准回到原商店卡槽）；
  - **两段式定朝向 & 棋盘干员原地转向**：从整备区拖放干员落位棋盘后弹出十字朝向轮盘，推摇杆/十字键四向滑动落位并伴随微震动；**对已在棋盘上的干员连按两次 `A`** 自动执行往返出格回环拖拽（`smooth_drag_loopback`），不离位即可呼出朝向盘原地重置朝向；
  - **右侧策略头像（休整/作战双态 + `LT+RT` 一键释放）与左下交流表情（`FocusZone.EMOTE_PANEL`）**：局内任意时刻同捏 **`LT + RT`** 即可无需移动焦点一键点击当前阶段的右侧本局策略头像（自动适配休整期右上中与作战期右下费用栏上方双态坐标）；亦可从棋盘最右列按右进入 `FocusZone.STRATEGY`，支持 `RT+A`/`A->A` 原地点击释放、`X` 查说明或拖拽至干员/商店卡槽；按 `LT + D-Pad 下`（或在队友栏底部继续按下）自动收起商店打开左下 `2x3` 交流表情面板，全程锁焦防逃逸，支持方向键选表情、`RS` 上下/左右推杆或 `LB`/`RB` 顺滑翻页、`A` 发送与 `B` 显式关闭；
  - **多盟约全主题感知、`>7` 横向滑动与任意相位精准吸附**：采用暗芯亮环 + 满层高光双通道圆环评分与局部带扫频梳状相位匹配，精准识别三套主题 `0~7` 居中盟约与 `>7` 溢出态及满层高光徽章；在顶部盟约栏推 **`RS`**（或作战期 `LB`/`RB`）拖拽滚动至任意停靠位置后，吸附选框与点击坐标实时锁定实测徽章圆心，可见数波动时绝不误跳右侧放大镜；
  - **回合结束 & `ESC` 离开双确认弹窗（`MODAL_CONFIRM`）**：零模板抗剪影识别两类确认窗，自动检测是否存在「本局不再提示」勾选框——回合确认窗支持三项切换（点不再提示自动回移聚焦「确认」），`ESC` 退出确认窗自动精简为「取消 / 确认」双项防误操作；
  - **4 点单应性透视、Boss 战镜像战场自动切换与 SIFT 三态镜头补偿**：通过单应性矩阵 $H$ 精准贴合 `4x7` 3D 俯视梯形棋盘，内置经 OpenCV SIFT 实机标定的 `shop_open` 镜头缩小补偿（中位误差 `1.1px`）及角色特写四栏导航；多人 Boss 战分配至右侧时自动识别并防抖锁存 3D 棋盘与 5 槽装备台水平镜像（保持 10 槽整备区与底部商店原位不变，HUD 顶签附带 ` · 镜像战场` 提示）；
  - **动态 4/5/6 槽商店鲁棒识别（双灰按钮零色相结构 + 三主题置灰）与 UAC 截屏自愈**：通过上移黑底白字横幅 + 按钮底缘梯度 + 4 固定槽竖边暗缝三联结构，在刷新与冻结按钮同时变灰及三主题全置灰状态下仍 100% 准确识别商店展开、4/5/6 槽位、各色/灰态升级卡与 `[ NO INFO ]` 空槽；后台 `mss` 采样支持 UAC 安全桌面切换后自动惰性重建自愈并拦截 DX11 `PrintWindow` 全黑伪帧；
  - **防误触准备与官方 `G` 键升本**：休整期准备就绪默认需 **长按 `Start` 0.35 秒**（HUD 充能环避让顶部盟约栏）；原生快捷键模式下按 `Y` 升本直接发送官方 **`G`** 键，彻底杜绝鼠标误买商品卡。
- **双模式兼容官方 PC 端与模拟器**：
  - 支持《明日方舟》官方 PC 客户端（`Arknights.exe`）与主流安卓模拟器（MuMu 模拟器、雷电模拟器），自动剔除窗口边框与 16:10 / 21:9 黑边；
  - 可在系统托盘一键切换 **「官方 PC 原生快捷键模式」**（优先发送实机校准的 `A`/`S`/`D`/`G`/`C`/`W`/`Q`/`X`/`Esc` 硬件扫描码）与 **「纯鼠标坐标点击模式」**（模拟器免配键即用）。
- **纯白极简 PRTS 桌面主控台 & H1/H2 透明穿透悬浮 HUD**：
  - **纯白极简桌面主控前端 (`PRTSDashboardWindow`)**：致敬终末地 / 莱茵纯白科研美学（瓷白主底 + 顶部水平琥珀下划线导航 + 白底细边按钮 + 空心框琥珀小勾开关），普通窗口层级绝不抢占游戏焦点，关闭后自动最小化至托盘零后台开销；内置四大分区——**总览（16Hz 实时双摇杆死区靶盘 / 扳机细条 / 按键高亮阵列 + 8 项快捷开关含「截屏/共享时隐藏 HUD」）**、**调校（7 项手感滑块 + 实时响应曲线可视化调校，一键写入 `user_override.json` 热刷新）**、**键位（9 卡卫戍协议全流程矢量按钮图示简报）**、**系统（UAC、截屏隔离状态与 SIFT 补偿矩阵诊断档案）**；
  - **纯白极简 H1/H2 鼠标穿透 HUD（支持录屏/共享可见热切换）**：白底细灰边顶签配 `2px` 琥珀竖线、全空心四折角白色锁定框（待确认内点琥珀小点）、白色细虚线抓取轨迹、H2 十字细轴四向定朝向箭头与通用矢量 Xbox 按键图示（圆内三横线 `START`、H2 双环 `LS/RS`、方向点亮十字键），默认启用 `WDA_EXCLUDEFROMCAPTURE` 防截屏自污染，同时可在主控台或托盘一键关闭「截屏/共享时隐藏 HUD」切换至 `WDA_NONE`（OBS 录屏与屏幕共享可见 HUD 且实测对视觉识别零干扰）；
  - 按 `Back + Start` 或在主控台右上角点击「启动校准向导 →」即可呼出多视图态可视化校准面板，鼠标直接拖动控制点实时预览 `4x7` 透视网格并一键截取保存本机局内场景模板。

## 环境要求与安装

- **操作系统**：Windows 10 / Windows 11（64 位）
- **Python 版本**：Python `3.12` 或更高版本
- **手柄设备**：支持标准 XInput 协议的 Xbox Series / Xbox One / Xbox 360 手柄或兼容手柄

### 1. 创建虚拟环境并安装依赖

在项目根目录 `arkcontroller` 下打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -e .
```

如需运行完整自动化测试套件与覆盖率统计，可一并安装开发依赖：

```powershell
.\.venv\Scripts\pip install -e ".[dev]"
```

### 2. 启动运行

```powershell
# 标准启动（默认检测并在需要时请求管理员 UAC 提权）
.\.venv\Scripts\arkcontroller

# 或以 Python 模块方式启动
.\.venv\Scripts\python -m arkcontroller.main
```

### 3. 命令行参数说明

| 参数 | 说明 |
| :--- | :--- |
| `--config-dir <路径>`（别名 `--config`） | 指定自定义配置目录（默认自动加载仓库根目录 `configs/`） |
| `--minimized` | 启动时最小化常驻系统托盘，不自动弹出 PRTS 桌面主控台窗口（UAC 提权重启时自动透传） |
| `--no-overlay` | 启动时隐藏透明 HUD 悬浮层（后续可在主控台或系统托盘随时重新开启） |
| `--no-elevate` | 跳过启动时的 UAC 管理员提权提示（适合模拟器或本地调试环境） |
| `--calibrate` | 启动后直接打开可视化校准向导面板 |
| `--dry-run` | 自动化冒烟测试模式：完成全模块装配与数个主循环 tick 后自动优雅退出 |
| `--log-level <级别>` | 设置日志详细级别：`DEBUG` / `INFO` / `WARNING` / `ERROR`（默认 `INFO`） |

## 关于管理员权限（UAC）与安全说明

1. **为什么启动时会请求管理员权限？**  
   《明日方舟》官方 PC 客户端（`Arknights.exe`）默认以高完整性级别（管理员身份）运行。根据 Windows **UIPI（用户界面特权隔离）** 安全机制，普通权限进程向管理员窗口发送的 `SendInput` 键鼠事件会被操作系统静默拦截。因此，控制官方 PC 客户端时必须以同等管理员权限启动 `ArkController`。
2. **如果我使用的是安卓模拟器（MuMu / 雷电）怎么办？**  
   若模拟器以普通权限运行，可使用 `--no-elevate` 启动，或在 UAC 弹窗选择取消——程序会自动给出提示并降级为标准权限继续运行。
3. **是否安全？会触发反作弊吗？**  
   本程序定位为 **纯外部无障碍外设映射工具**，只调用系统标准 `XInput1_4.dll`、`SendInput`、`mss`/`PrintWindow` 与 Qt 置顶透明绘制，**零内存读写、零代码注入、零驱动挂钩**，不对游戏本体文件做任何修改。

## 快速校准指南

系统内置基于实机标定的标准 `16:9` 局内布局预设，开箱即可上手；如果不同赛季 UI 主题或模拟器画幅存在细微偏移，建议花 30 秒完成一次本机校准：

1. 启动《明日方舟》并进入卫戍协议局内休整期，同时保持 `ArkController` 运行。
2. 同时按下手柄 **`Back + Start`**（或在右下角系统托盘右键菜单点击 **「打开可视化校准向导」**）。
3. **对齐棋盘透视网格**：可在左上角下拉切换校准视图态（`默认态` / `商店展开态` / `选取角色态`），用鼠标直接拖动青色菱形控制点 **棋盘左上 / 右上 / 右下 / 左下** 至实际战斗地块外角，画布将实时绘制 `4x7` 单应性透视网格线与各格中心点（如需适配特殊地图，可在面板微调行列维度）。
4. **对齐商店、整备区与装备栏**：分别拖动绿色（商店）、琥珀色（10 格整备区）、紫色（5 格装备栏）的首尾控制点，使预览槽位方框与游戏内卡槽精准重合。
5. **（可选）采集本机局内场景模板**：在对应界面打开校准面板，下拉选择对应局内 `GameScene`（`休整运营` / `三选一弹窗` / `回合确认` / `自动作战`），点击 **「截取当前画面作为场景识别模板」**，程序将自动隐藏遮罩截取干净 ROI 存入 `assets/templates/` 并即时热重载。
6. 点击 **「保存并生效」**：所有修改会安全合并写入 `configs/user_override.json`（不覆盖默认配置），并立即热刷新至调度引擎与 HUD，关闭后即刻恢复鼠标穿透操控。

## PRTS 桌面主控台与系统托盘功能一览

程序启动后默认展示 **纯白极简 PRTS 桌面主控台**（可使用 `--minimized` 静默启动），关闭主控台窗口将自动缩小常驻 Windows 右下角系统托盘（内置动态绘制的白底炭灰细边 + 琥珀状态点矢量图标，暂停时自动切换双竖条）：
- **单击或双击托盘图标**（或右键点击顶部「打开 PRTS 主控台」）可随时唤出并前置主控台；
- 在主控台「总览」与「调校」中可实时查看 **手柄遥测靶盘与窗口绑定状态**、通过空心框琥珀小勾开关切换 8 项运行态配置（含 **「截屏/共享时隐藏 HUD」** 热切换），并拖动滑块实时预览响应曲线后一键持久化保存至 `configs/user_override.json`；
- 托盘白底细边浅色菜单同步提供快捷控制：**暂停 / 恢复手柄控制**（`LT + Back`）、**显示 / 隐藏悬浮 HUD**、**截屏/共享时隐藏 HUD**、切换 **左摇杆模式（吸附跳格 ↔ 自由光标）**、切换 **「官方 PC 原生快捷键模式 / 纯鼠标坐标模式」**、打开 **可视化校准向导**、**重新加载配置文件** 及完全退出程序。

## 常见问题（FAQ）

**Q1：进入游戏后按手柄没有任何反应，但系统托盘显示手柄已连接？**  
A：请检查两点：① 系统托盘是否显示已成功绑定游戏窗口且处于「前台激活」状态（点击一下游戏画面使其获得焦点）；② 若使用官方 PC 端 `Arknights.exe`，请确认 `ArkController` 已以管理员身份运行（未跳过 UAC）。

**Q2：自动场景识别没有准确切换到当前阶段怎么办？**  
A：任何时候单击手柄 **`Back (View)`** 键都可以在「自动识别 -> 休整运营 -> 决策弹窗 -> 回合确认 -> 自由鼠标」间手动循环切换并锁定模式（HUD 顶部会显示 `手动锁层` 标记）；在手动锁定「休整运营」期间，商店开关与 4/5/6 槽位仍会持续自动同步。

**Q3：在 16:10 笔记本或 21:9 带鱼屏上 HUD 框位置偏了吗？**  
A：不会。`WindowTracker` 会自动开启 Windows Per-Monitor DPI V2 感知，并从游戏客户区扣除上下或左右黑边提取严格居中 `16:9` 核心视口，HUD 与鼠标坐标均基于同一物理视口对齐。

**Q4：如何在不连接实体手柄的情况下验证程序安装正常？**  
A：运行冒烟测试与单元测试：

```powershell
.\.venv\Scripts\python -m arkcontroller.main --no-elevate --dry-run
.\.venv\Scripts\pytest -v --cov=arkcontroller tests/
```
