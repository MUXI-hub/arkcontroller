# 《明日方舟》卫戍协议 Xbox 手柄全流程操作速查手册

本手册完整涵盖使用 **ArkController** 通过 Xbox 手柄畅玩《明日方舟》**「卫戍协议」**（单人规程 / 盟约与多人联机模式）的全部按键操作与实战技巧。

---

## 一、核心操控理念：精准跳格 × 自由光标无缝切换

在任何界面下，系统同时为你提供两套零割裂的操控方式：
1. **槽位焦点吸附模式（默认推荐）**：使用 **十字键（`D-Pad`）** 与 **肩键（`LB`/`RB`）** 在按钮、商店卡牌、10 格整备区、5 格装备栏和 `5x9` 透视棋盘格之间高速精准跳格，HUD 会用青蓝色（`#00E5FF`）高亮当前选中目标。
2. **自由虚拟鼠标模式（随时兜底）**：任意时刻**轻推左摇杆（`LS`）**，系统立即切换为自由虚拟光标（微推可像素级精准微调，推满高速跨屏），按 **`A`** 即左键点击，推 **`RS`** 滚动列表。需要回到吸附网格时，只需**按一下十字键或 `LB`/`RB`** 即可瞬间恢复！

## 二、全局通用热键（全阶段生效）

| Xbox 手柄按键 | 功能 | 详细说明 |
| :--- | :--- | :--- |
| **`LS`（左摇杆推动）** | 自由虚拟鼠标光标 | 三次方双速曲线，轻推精调、推满跨屏，随时点击任意角落 |
| **`RS`（右摇杆推动）** | 鼠标垂直 / 水平滚轮 | 在编队干员列表、图鉴、奖励页与结算明细中流畅滚动 |
| **`Back (View)` 单击** | 手动循环切换场景层 | 在「菜单编队 -> 局内运营 -> 三选一弹窗 -> 纯自由光标」间循环并开启 `手动锁层` |
| **`Back + Start`** | 打开 / 关闭可视化校准向导 | 实时拖动棋盘 4 角透视网格、槽位锚点或截取场景识别模板 |
| **`LT + Back`** | 暂停 / 恢复手柄映射 | 临时挂起所有映射输出（游戏切至后台时也会自动暂停） |

## 四、局内核心：休整期商店运营（`BATTLE_PREP`）

进入局内休整期后，焦点区分为四大板块：**`商店` ↔ `整备区 (10 槽)` ↔ `棋盘 (5x9)` ↔ `装备栏 (5 槽)`**。

- 按 **`LB` / `RB`** 可在四大区域间一键循环切换；
- 在商店区按 **`D-Pad 上`** 可自然上移至整备区，在整备区按 **`D-Pad 上`** 可自然进入棋盘，按 **`D-Pad 下`** 回到商店，符合空间直觉！

| 按键 | 常规浏览态功能 | 对应官方 PC 快捷键 / 说明 |
| :--- | :--- | :--- |
| **`LB` / `RB`** | 切换焦点区域 | `商店 ↔ 整备区(10槽) ↔ 棋盘(5x9) ↔ 装备栏(5槽)` |
| **`D-Pad`** | 槽位内跳格与跨区移动 | 按住可连续快速跳格（支持自动连发） |
| **`A`** | **商店**：选中 / 买牌<br>**整备 / 棋盘 / 装备**：抓取目标 | 抓起干员或装备后立即进入「抓取持有态」，HUD 绘制琥珀色虚线连线 |
| **`RT + A`** | **一键极速连买** | 自动连续完成商店卡牌“选中 + 确认购买”双击，D 牌抢卡效率拉满 |
| **`B`** | 取消选中 / 关闭详情侧栏 | 退出当前干员或装备属性预览 |
| **`X`** | **刷新商店（D 牌）** | 触发 `D` 键（纯鼠标模式下点击刷新按钮） |
| **`Y`** | **升级商店等级（升本）** | 点击指挥中心升本按钮 |
| **`RS`（右摇杆按下）** | **冻结 / 解冻商店** | 触发 `R` 键（纯鼠标模式下点击锁定按钮） |
| **`Start`（长按 0.35s）** | **准备就绪 / 开始战斗** | 防误触设计！按住期间屏幕上方出现琥珀色进度环，读满触发 `Space` 开战 |

## 五、局内核心：干员部署、两段式定朝向、换位、穿装与售卖

### 1. 标准「整备区抓人 -> 棋盘落位 -> 四向定朝向」流程

```text
① 在整备区选中干员按 [A]   ──▶  进入「抓取持有态」，源槽位亮起琥珀色虚线框
② 用 [D-Pad] 或 [LB/RB] 移至棋盘目标格，按 [A]
                            ──▶  自动平滑拖拽干员至该透视格心，进入「定朝向态」
                                 HUD 在该格弹出十字四向轮盘（上 / 下 / 左 / 右）
③ 推 [左/右摇杆] 或按 [十字键] 选择朝向
                            ──▶  瞬间完成第二段滑动定朝向落位，手柄轻微震动确认！
```

> **随时安全中断**：无论是在「抓取持有态」还是「定朝向态」，只要按下 **`B`** 即可立即取消本次抓取或撤回部署，回到安全浏览态。

### 2. 抓取持有态（`HOLDING_UNIT` / `HOLDING_EQUIP`）快捷操作表

| 按键 | 持有干员时 (`HOLDING_UNIT`) | 持有装备/法术时 (`HOLDING_EQUIP`) |
| :--- | :--- | :--- |
| **`LB` / `RB`** | 在 `整备区 ↔ 棋盘` 间快速切区 | 在 `装备栏 ↔ 棋盘 ↔ 整备区` 间快速切区 |
| **`D-Pad`** | 选择目标落位格（定朝向态直接选方向） | 移至目标干员所在格 |
| **`A`** | 移至**棋盘格**：落位并进入定朝向轮盘<br>移至**整备格**：平滑拖拽互换位置 | 平滑拖拽给目标干员穿戴装备或释放策略 |
| **`B`** | 取消抓取 / 取消定朝向部署 | 取消抓取装备 |
| **`X`** | **快速出售干员**（自动区分场上 `E` / 整备 `Q`；纯鼠标模式拖拽至出售区） | **快速出售装备**（触发 `Q` 或拖至出售区） |
| **`Y`** | **联机赠卡**：平滑拖拽赠送给当前选中的联机队友 | **联机赠予装备**：拖拽赠给联机队友 |

## 七、`LT` 修饰层：信息速查与多人联机互动（局内全程可用）

在休整期与自动作战期，按住 **`LT`（左扳机）** 即可激活信息与联机速查组合键（组合触发后不会误触发单键动作）：

| 组合键 | 功能 | 对应快捷键 / 说明 |
| :--- | :--- | :--- |
| **`LT + D-Pad 左`** | 展开 / 收起 **盟约容器详情面板** | 触发 `` ` `` (`~`) 键，展开后可用十字键查看各盟约羁绊层数 |
| **`LT + D-Pad 上`** | 查看 **敌方波次信息与出怪路线** | 触发 `Tab` 键（或点击右上角放大镜预览红门路线） |
| **`LT + D-Pad 下`**（或 **`LS` 按下**） | 呼出 **联机互动表情轮盘** | 触发 `Z` 键，推左摇杆选定表情松开即发送 |
| **`LT + D-Pad 右`** | 循环切换查看 **联机队友 1~4 棋盘视角** | 顺序切换 1 / 2 / 3 / 4 号队友战场，同时更新 `Y` 键赠卡默认目标 |
| **`LT + A / B / X / Y`** | **直达联机队友 1 / 2 / 3 / 4 号位** | 分别对应队友 1（`A`）、队友 2（`B`）、队友 3（`X`）、队友 4（`Y`） |
| **`LT + RB`** | **一键撤退场上干员** | 触发 `A` 键撤退（可在配置中设 `allow_retreat_chord: false` 关闭防误触） |
| **`LT + Start`** | 打开右上角 **暂停 / 设置菜单** | 单人模式随时暂停思考，或查看对局设置与退出 |

## 八、作战期（`BATTLE_COMBAT`）与对局结算（`SETTLEMENT`）

- **作战期**：自动作战期间仍可通过 **`LT` 组合键** 随时查看盟约、敌方波次、切换队友视角或发送互动表情；推 **`LS`** 可自由查看干员状态面板，按 **`LT + Start`** 可暂停或打开菜单。
- **结算界面**：使用 **`D-Pad`** 在结算统计按钮间跳转，按 **`RS`** 滚动战绩与奖励明细，按 **`A`** 或 **`Start`** 确认继续并返回活动主界面。

## 九、个性化手感微调指南

无需修改默认文件，你可以直接在 `configs/user_override.json` 中覆写以下常用参数（保存后在托盘点击 **「重新加载配置文件」** 立即生效）：

```json
{
  "keymap": {
    "left_deadzone": 0.14,
    "right_deadzone": 0.16,
    "cursor_max_speed_px": 1400.0,
    "cursor_gamma": 2.2,
    "ready_hold_ms": 350,
    "use_native_keyboard_shortcuts": true,
    "vibration_enabled": true,
    "allow_retreat_chord": true
  }
}
```

- **希望单击 `Start` 立即开战**：将 `"ready_hold_ms"` 调小（如 `0` 或 `120`）。
- **觉得摇杆微调太快或太慢**：适当调高 `"cursor_gamma"`（如 `2.5` 更易微调）或调整 `"cursor_max_speed_px"`。
- **使用未配键的安卓模拟器**：将 `"use_native_keyboard_shortcuts"` 设为 `false`，或在系统托盘右键直接取消勾选「官方 PC 原生快捷键模式」。
