# 《明日方舟》卫戍协议 Xbox 手柄全流程操作速查手册

本手册完整涵盖使用 **ArkController** 通过 Xbox 手柄畅玩《明日方舟》**「卫戍协议」**（单人规程 / 盟约与多人联机模式）的全部按键操作与实战技巧。

---

## 一、核心操控理念：左摇杆/十字键精准跳格 × `LS` 自由光标无缝切换

在任何界面下，系统同时为你提供两套零割裂的操控方式：
1. **槽位焦点吸附模式（默认推荐）**：**左摇杆（`LS` 推动）可直接代替十字键（`D-Pad`）**，配合肩键（`LB`/`RB`）在按钮、商店卡牌、10 格整备区、5 格装备栏和透视棋盘格之间高速精准跳格（支持滞回防抖与推住连发），HUD 会用青蓝色（`#00E5FF`）高亮当前选中目标。
2. **自由虚拟鼠标模式（随时兜底）**：任意时刻**按下左摇杆（`LS` 按下）**，系统立即切换为自由虚拟光标（轻推左摇杆像素级精准微调，推满高速跨屏），按 **`A`** 即左键点击，推 **`RS`** 滚动列表。再次**按下 `LS` 或按一下十字键 / `LB`/`RB`** 即可瞬间恢复吸附导航！

## 二、全局通用热键（全阶段生效）

| Xbox 手柄按键 | 功能 | 详细说明 |
| :--- | :--- | :--- |
| **`LS`（左摇杆推动）** | 代替十字键离散跳格 / 自由光标移动 | 默认在吸附模式下代替十字键导航；切至自由光标模式后控制鼠标指针 |
| **`LS`（左摇杆按下）** | 一键切换「吸附导航 ↔ 自由光标」 | 随时切出自由鼠标点选任意角落，再按一次立即恢复吸附 |
| **`RS`（右摇杆推动）** | 鼠标垂直 / 水平滚轮 | 在编队干员列表、图鉴、奖励页与结算明细中流畅滚动 |
| **`Back (View)` 单击** | 手动循环切换场景层 | 在「菜单编队 -> 局内运营 -> 三选一弹窗 -> 纯自由光标」间循环并开启 `手动锁层` |
| **`Back + Start`** | 打开 / 关闭可视化校准向导 | 支持分别校准「默认态 / 商店展开态 / 选取角色态」透视网格与采集识别模板 |
| **`LT + Back`** | 暂停 / 恢复手柄映射 | 临时挂起所有映射输出（游戏切至后台时也会自动暂停） |

## 四、局内核心：休整期商店运营（`BATTLE_PREP`）

进入局内休整期后，焦点区分为四大板块：**`商店 (1本4槽 / 2本5槽 / 4本6槽自动适配)` ↔ `整备区 (10 槽)` ↔ `装备栏 (5 槽)` ↔ `棋盘 (4x7)`**。

- 按 **`LB` / `RB`** 可在四大区域间一键循环切换；
- 商店升至二本/四本向左侧延伸增加栏位时，系统自动视觉识别当前为 `4 / 5 / 6` 槽，保持卡片大小与间距不变向左侧扩展选框，并同步左移 **`Y`（升级商店）** 点击位置；
- 纵向导航完全贴合屏幕真实上下排布：底部 **`商店`** 向上进 **`整备区`** -> 向上进 **`装备栏`** -> 向上进 **`棋盘`**（切入棋盘自动收起商店恢复全屏视角），向下则逐级返回 **`商店`**（自动展开商店并套用 `1.1px` 精度 SIFT 缩放补偿）！

| 按键 | 常规浏览态功能 | 对应官方 PC 快捷键 / 说明 |
| :--- | :--- | :--- |
| **`LB` / `RB`** | 切换焦点区域（自动联动商店开合） | `商店 ↔ 整备区 ↔ 棋盘 ↔ 装备栏`；切入商店自动按 `A` 展开，切去棋盘自动按 `A` 收起 |
| **`左摇杆 / D-Pad`** | 槽位内跳格与跨区移动 | 支持自动连发，自适应底部横向装备栏与侧边竖向装备栏 |
| **`A`** | **商店**：选中 / 买牌<br>**整备 / 棋盘 / 装备**：无缩放虚拟抓取 | 抓取干员时不提前单击诱发镜头缩放，确保拖拽落位与框选精准对齐 |
| **`RT + A`** | **商店**：一键极速连买<br>**整备 / 棋盘**：查看角色详情 | 在整备区/棋盘按 `RT+A` 进入「角色详情模式」：自动吸附左侧 `特质 / 技能 / 特性 / 天赋` 四栏，支持 `X` 出售、`Y` 撤回、`B` 点空白区退出 |
| **`LT + LB`** | **手动展开 / 收起商店** | 触发官方原生快捷键 `A`，随时切换商店并同步 `shop_open` 三区缩放补偿 |
| **`B`** | 退出角色详情 / 收起商店 | 选中角色态按 `B` 左键点安全空白区退出并恢复标准视角；商店区按 `B` 收起商店并回到整备区 |
| **`X`** | **刷新商店（D 牌）** | 商店未展开时自动先按 `A` 展开，再触发官方快捷键 `D`（纯鼠标模式点击刷新按钮） |
| **`Y`** | **升级商店等级（升本）** | 商店未展开时自动先按 `A` 展开，再点击最左侧升级商店灰卡 |
| **`RS`（右摇杆按下）** | **冻结 / 解冻商店** | 商店未展开时自动先按 `A` 展开，再触发官方快捷键 `S`（纯鼠标模式点击冻结按钮） |
| **`Start`（长按 0.35s）** | **准备就绪 / 开始战斗** | 防误触设计！按住期间屏幕上方出现琥珀色进度环，读满触发官方快捷键 `C` 开战 |

## 五、局内核心：干员部署、两段式定朝向、换位、穿装与售卖

### 1. 标准「整备区抓人 -> 棋盘落位 -> 四向定朝向」流程

```text
① 在整备区选中干员按 [A]   ──▶  进入「抓取持有态」，源槽位亮起琥珀色虚线框
② 用 [D-Pad] 或 [LB/RB] 移至棋盘目标格，按 [A]
                            ──▶  自动平滑拖拽干员至该透视格心，进入「定朝向态」
                                 HUD 在该格弹出十字四向轮盘（上 / 下 / 左 / 右）
③ 推 [左/右摇杆] 或按 [十字键] 选择朝向
                            ──▶  瞬间完成第二段滑动定朝向落位，手柄轻微震动确认！
```

> **随时安全中断**：无论是在「抓取持有态」还是「定朝向态」，只要按下 **`B`** 即可立即取消本次抓取或撤回部署，回到安全浏览态。

### 2. 抓取持有态（`HOLDING_UNIT` / `HOLDING_EQUIP`）快捷操作表

| 按键 | 持有干员时 (`HOLDING_UNIT`) | 持有装备/法术时 (`HOLDING_EQUIP`) |
| :--- | :--- | :--- |
| **`LB` / `RB`** | 在 `整备区 ↔ 棋盘` 间快速切区 | 在 `装备栏 ↔ 棋盘 ↔ 整备区` 间快速切区 |
| **`D-Pad`** | 选择目标落位格（定朝向态直接选方向） | 移至目标干员所在格 |
| **`A`** | 移至**棋盘格**：落位并进入定朝向轮盘<br>移至**整备格**：平滑拖拽互换位置 | 平滑拖拽给目标干员穿戴装备或释放策略 |
| **`B`** | 取消抓取 / 取消定朝向部署（左键点菱形左上 `×`） | 取消抓取装备 |
| **`X`** | **快速出售干员**（官方原生快捷键 `X`；纯鼠标模式拖至右下金黄售出区） | **快速出售装备**（触发 `X` 或拖至出售区） |
| **`Y`** | **联机赠卡**：平滑拖拽赠送给当前选中的联机队友 | **联机赠予装备**：拖拽赠给联机队友 |

## 七、`LT` 修饰层：信息速查与多人联机互动（局内全程可用）

在休整期与自动作战期，按住 **`LT`（左扳机）** 即可激活信息与联机速查组合键（组合触发后不会误触发单键动作）：

| 组合键 | 功能 | 对应快捷键 / 说明 |
| :--- | :--- | :--- |
| **`LT + D-Pad 左`** | 展开 / 收起 **盟约容器详情面板** | 点击顶部左侧青色放大镜按钮，查看核心与附加盟约羁绊层数 |
| **`LT + D-Pad 上`** | 查看 **敌方波次信息与出怪路线** | 触发官方快捷键 `W`（或点击顶部右侧黄色放大镜预览出怪路线） |
| **`LT + D-Pad 下`** | 呼出 **联机互动表情轮盘** | 触发 `Z` 键，推左摇杆选定表情松开即发送 |
| **`LT + D-Pad 右`** | 循环切换查看 **联机队友 1~4 棋盘视角** | 顺序切换 1 / 2 / 3 / 4 号队友战场，同时更新 `Y` 键赠卡默认目标 |
| **`LT + A / B / X / Y`** | **直达联机队友 1 / 2 / 3 / 4 号位** | 分别对应队友 1（`A`）、队友 2（`B`）、队友 3（`X`）、队友 4（`Y`） |
| **`LT + RB`** | **一键撤退场上干员** | 触发官方快捷键 `Q` 撤退（可在配置中设 `allow_retreat_chord: false` 关闭防误触） |
| **`LT + Start`** | 打开左上角 **暂停 / 设置菜单** | 单人模式随时暂停思考，或查看对局设置与退出 |

## 八、作战期（`BATTLE_COMBAT`）与对局结算（`SETTLEMENT`）

- **作战期**：自动作战期间仍可通过 **`LT` 组合键** 随时查看盟约、敌方波次、切换队友视角或发送互动表情；推 **`LS`** 可自由查看干员状态面板，按 **`LT + Start`** 可暂停或打开菜单。
- **结算界面**：使用 **`D-Pad`** 在结算统计按钮间跳转，按 **`RS`** 滚动战绩与奖励明细，按 **`A`** 或 **`Start`** 确认继续并返回活动主界面。

## 九、个性化手感微调指南

无需修改默认文件，你可以直接在 `configs/user_override.json` 中覆写以下常用参数（保存后在托盘点击 **「重新加载配置文件」** 立即生效）：

```json
{
  "keymap": {
    "left_deadzone": 0.14,
    "right_deadzone": 0.16,
    "cursor_max_speed_px": 1400.0,
    "cursor_gamma": 2.2,
    "ready_hold_ms": 350,
    "use_native_keyboard_shortcuts": true,
    "vibration_enabled": true,
    "allow_retreat_chord": true
  }
}
```

- **希望单击 `Start` 立即开战**：将 `"ready_hold_ms"` 调小（如 `0` 或 `120`）。
- **觉得摇杆微调太快或太慢**：适当调高 `"cursor_gamma"`（如 `2.5` 更易微调）或调整 `"cursor_max_speed_px"`。
- **使用未配键的安卓模拟器**：将 `"use_native_keyboard_shortcuts"` 设为 `false`，或在系统托盘右键直接取消勾选「官方 PC 原生快捷键模式」。
