# 《明日方舟》卫戍协议 Xbox 手柄全流程操作速查手册

本手册完整涵盖使用 **ArkController `v0.3.3`** 通过 Xbox 手柄畅玩《明日方舟》**「卫戍协议」**（单人规程 / 盟约与多人联机含 Boss 战镜像战场，全面适配三套主题 UI 与置灰态）的全部按键操作与实战技巧。

---

## 一、核心操控理念：局外自由鼠标 × 局内精准吸附跳格

系统按界面特征自动切换最顺手的操控模式：
1. **局外界面与设置页（`自由鼠标`）**：活动入口、模式/分队选择、战前编队、设置页与对局结算均不依赖脆弱的静态菜单坐标，**左摇杆（`LS` 推动）始终直接平滑驱动虚拟鼠标光标**，所见即所得。
2. **局内槽位焦点吸附模式（默认推荐）**：进入对局休整期、决策弹窗与回合确认弹窗后，**左摇杆（`LS` 推动）自动转为代替十字键（`D-Pad`）**，配合肩键（`LB`/`RB`）在商店、10 格整备区、5 格装备栏、4x7 透视棋盘、右侧策略头像、顶部放大镜与羁绊栏、左侧队友头像间高速精准跳格，HUD 以极简白色外衬暗描边四角折标高亮当前目标（待确认或抓取目标态四角内侧点亮琥珀小点）。
3. **局内随时切出自由光标兜底**：局内任意时刻**按下左摇杆（`LS` 按下）**，即刻切为自由虚拟鼠标（轻推像素级微调、推满高速跨屏）；再**按一次 `LS` 或按十字键 / `LB`/`RB`** 瞬间恢复吸附导航！

| :--- | :--- | :--- |

## 三、局外阶段与设置界面（`UNKNOWN_FREE_CURSOR`：纯模拟自由鼠标）

程序启动时默认处于 **`自由鼠标`** 模式；在活动主界面、模式/分队准备、干员编队、干员列表、设置页面、加载过渡及对局结算页，系统依托局内双锚点防误判门禁始终稳定保持在 **`自由鼠标`** 模式（HUD 顶部显示 `PRTS // 自由鼠标`），并在窗口前台激活或你移动实体鼠标时自动无损同步 HUD 分离式细线准星与真实光标位置（不会影响左摇杆低速微推的亚像素累加）：

| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **`LS`（左摇杆推动）** | 自由虚拟鼠标指针移动 | 始终直接移动鼠标光标（不受局内 `left_stick_mode="dpad"` 限制），三次方双速曲线兼顾微调与跨屏 |
| **`RS`（右摇杆推动）** | 鼠标垂直 / 水平滚轮 | 流畅滚动编队干员池、奖励列表、设置选项与结算统计明细 |
| **`A`** | 鼠标左键单击 | 点击光标指向的任意按钮、干员卡片、技能/模组或结算确认 |
| **`RT + A`** | 鼠标左键双击 | 在需要连续双击确认的界面快速触发双击 |
| **`B`** | 返回 / 关闭弹窗 | 发送 `Esc` 键返回上一级界面或关闭侧栏弹窗 |

## 四、局内核心：休整期商店运营（`BATTLE_PREP`）

进入局内休整期后，核心运营区域覆盖：**`商店 (1本4槽 / 2本5槽 / 4本6槽自动适配)` ↔ `整备区 (10 槽)` ↔ `装备栏 (5 槽)` ↔ `棋盘 (4x7)` ↔ `右侧策略头像`**。

- 按 **`LB` / `RB`** 可在四大核心区（商店 / 整备区 / 棋盘 / 装备栏）间循环切换；
- **商店双灰与多槽自适应**：商店升至二本（5 槽）或四本（6 槽）向左延伸时，即便刷新与冻结双按钮同时变灰或处于三套主题全按钮置灰态，系统依然依托零色相结构识别精准保持 `shop_open` 三区缩放补偿并自动同步 4/5/6 栏位（兼容各主题高亮/暗屏/置灰升级卡与已售空 `[ NO INFO ]` 空槽，**手动锁层**下同样实时同步）；
- **Boss 战右侧镜像战场自动适配**：多人 Boss 战被分配至右侧导致 3D 棋盘与 5 槽装备台水平镜像时，系统自动识别并防抖锁存镜像映射（HUD 顶部焦点签显示 ` · 镜像战场`，弹窗或查看队友期间稳定保持，出局自动清零），方向键仍遵循直观屏幕左→右列序，同时保持 10 槽整备区与底部商店原位不变；
- 全屏物理空间跨区链路：
  - **上下链路**：顶部 **`本局信息放大镜 / 1~7 居中对称或 >7 溢出可滑动盟约栏 / 本轮出怪放大镜`** ↔ **`棋盘 (4x7)`** ↔ **`装备栏 (5 槽)`** ↔ **`整备区 (10 槽)`** ↔ 底部 **`商店`**；
    - 当激活盟约超过 7 个进入溢出态（HUD 显示 `羁绊 [k/7+]`）时，在顶部盟约栏推 **`RS`（右摇杆左右或上下）** 或作战期按 **`LB` / `RB`** 即可自动在顶部安全带平滑拖拽左右滑动盟约栏；滑动停留在任意水平位置（含满层高光金色盟约）时，选框与点击坐标都会实时锁定实测徽章圆心，可见数在 `7 ↔ 6` 波动时也不会误跳右侧放大镜；
  - **右侧链路**：从 **`棋盘`** 最右列继续按右即可跨入右侧 **`策略头像 (STRATEGY)`**（按左回棋盘、按上进右放大镜、按下进装备栏）；
  - **多人左侧链路**：多人联机模式下，从 **`棋盘`** 最左列继续按左即可跨入左侧纵向 **`队友头像栏 (1~4)`**，上下切换并按 **`A`** 查看队友战场（按右返回棋盘）。

| 按键 | 常规浏览态功能 | 对应官方 PC 快捷键 / 说明 |
| :--- | :--- | :--- |
| **`LB` / `RB`** | 切换核心运营区域（自动联动商店开合） | `商店 ↔ 整备区 ↔ 棋盘 ↔ 装备栏`；切入商店自动按 `A` 展开，切去棋盘自动按 `A` 收起 |
| **`左摇杆 / D-Pad`** | 槽位内跳格与全屏跨区移动 | 上入顶部放大镜与居中对称羁绊栏；右入策略头像；多人模式左入队友头像栏 |
| **`A`** | **商店**：连按两次防误触买牌（首次预选，2 秒内再按双击购买）<br>**整备 / 棋盘 / 装备 / 策略**：锁定抓取源<br>**顶部栏 / 队友栏**：查看本局信息、羁绊、出怪或队友视角 | 商店首次按 `A` 仅本地预选（HUD 显示 `再按A购买`）绝不发单击诱发详情抢焦点；抓取干员不提前单击诱发镜头缩放 |

| **`LT + LB`** | **手动展开 / 收起商店** | 触发官方原生快捷键 `A`，随时切换商店并同步 `shop_open` 三区缩放补偿（刷新/冻结双按钮变灰及三主题全置灰同样保持精准补偿） |
| **`B`** | 关闭队友面板 / 取消商店预选 / 关闭详情 / 收起商店 | 查看联机队友抽屉时按 **`B`** 优先点击左上角退出按钮右侧延迟区 `(0.1172, 0.0903)` 安全关闭（绝不误触右侧队友策略）；商店处于「再按A购买」预选态按 `B` 仅取消预选，再按 `B` 收起商店；角色详情与浮窗同样点击左上延迟安全区退出 |
| **`X`** | **刷新商店（D 牌）** / **策略区查看说明** | 在右侧策略头像区按 `X` 查看策略说明；其余浏览区自动展开商店并触发官方快捷键 `D` 刷新（纯鼠标模式点击刷新按钮） |
| **`Y`** | **升级商店等级（升本）** | 官方 PC 原生快捷键模式下直接触发 **`G`** 键安全升本，彻底避免鼠标坐标误买商品卡（纯鼠标模式下自动展开商店并点击同步左移后的升级卡） |
| **`RS`（右摇杆按下）** | **冻结 / 解冻商店** | 商店未展开时自动先按 `A` 展开，再触发官方快捷键 `S`（纯鼠标模式点击冻结按钮） |
| **`Start`（长按 0.35s）** | **准备就绪 / 开始战斗** | 防误触设计！按住期间屏幕上方出现琥珀色进度环，读满触发官方快捷键 `C` 开战（若资金/策略未用完弹出确认窗，系统自动切换至回合确认弹窗层） |

## 五、局内核心：干员部署、原地转向、换位、穿装与右侧策略头像

### 1. 标准「整备区抓人 -> 棋盘落位 -> 四向定朝向」流程

```text
① 在整备区选中干员按 [A]   ──▶  进入「抓取持有态」，源槽位亮起琥珀色虚线框
② 用 [左摇杆/D-Pad] 或 [LB/RB] 移至棋盘目标格，按 [A]
                            ──▶  自动平滑拖拽干员至该透视格心，进入「定朝向态」
                                 HUD 在该格弹出十字四向轮盘（上 / 下 / 左 / 右）
③ 推 [左/右摇杆] 或按 [十字键] 选择朝向
                            ──▶  瞬间完成第二段滑动定朝向落位，手柄轻微震动确认！
```

### 2. 棋盘干员原地设置转向（无需下场重摆）

```text
① 在棋盘选中已在场上的干员按 [A]    ──▶  锁定该干员源格（HOLDING_UNIT）
② 保持焦点在该干员格，原地再按一次 [A]
                                   ──▶  自动执行“出格 -> 回落原格”往返平滑回环拖拽
                                        触发游戏四向白色菱形定朝向盘并进入「定朝向态」
③ 推 [左/右摇杆] 或按 [十字键] 选择新朝向
                                   ──▶  完成原地转向并微震动确认（按 [B] 可取消转向）
```

### 3. 右侧策略头像操控（`FocusZone.STRATEGY` & 全局 `LT + RT` 快捷释放）

系统自动适配休整期（右上中 `(0.9605, 0.3243)`）与作战期（右下费用栏上方 `(0.9602, 0.7486)`）两套固定 `right_edge` 策略头像坐标（不受商店展开缩放影响）：

- **任意位置一键快捷释放**：局内休整期或作战期（非拖拽/定朝向中途），同时按下 **`LT + RT`**（不限先后顺序）即可无需移动焦点，一键点击当前阶段的右侧本局策略头像！
- **进入策略区直接点击释放**：从棋盘最右列按右进入右侧策略头像区，空闲态直接按 **`RT + A`** 一键点击释放；或按 **`A`** 锁定策略源（HUD 显示白色细虚线 `策略源`）后再按一次 **`A`** 原地点击释放。
- **查看策略说明**：空闲态按 **`X`** 点击策略头像左侧说明按钮查看详情，按 **`B`** 点击左上延迟安全区关闭。
- **拖拽策略至干员或商店卡槽**：
  1. 在策略头像区按 **`A`** 进入 **`HOLDING_STRATEGY`**（锁定 `策略源`）；
  2. 用方向键或 **`LB`/`RB`**（在 `策略 ↔ 棋盘 ↔ 整备区 ↔ 商店` 间循环）移动焦点至目标**棋盘干员格**、**整备区干员槽**或**商店卡槽**；
  3. 按 **`A`** 确认释放（若目标在商店且商店尚未展开，系统会自动先按 `A` 展开商店并等待动画就绪，再从固定策略头像位置平滑拖拽至选中的商店卡槽）；
  4. 任意时刻按 **`B`** 无点击安全取消抓取。

## 六、回合结束与 `ESC` 暂时离开确认弹窗（`MODAL_CONFIRM`）

休整期尚有未用完的资金/策略触发开战（长按 `Start`）或局内按 `Esc` 弹出「确认要暂时离开模拟吗？」时，系统零模板自动识别确认弹窗并默认吸附在右下角 **「确认」** 按钮（自动区分是否包含「本局不再提示」勾选框）：

| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **`左 / 右`（或 `LB / RB`）** | 切换「取消」 / 「确认」 | 左选左下角灰色「取消」，右选右下角暗红「确认」 |
| **`上 / 下`** | 切换「本局不再提示」勾选框（仅回合确认窗） | 回合确认窗向上切至「本局不再提示」、向下回「确认」；`ESC` 退出确认窗无此项时自动屏蔽 |
| **`A`** | 点击当前聚焦按钮 | 若点击「本局不再提示」，点击后焦点自动回移至「确认」，连按一次 `A` 即可直接开战 |
| **`B`** | **直接点击「取消」** | 一键取消开战或取消离开，立即返回局内继续操作 |
| **`Start` 或 `RT + A`** | **直接点击「确认」** | 无需移动焦点，一键确认当前弹窗 |
| **`X`** | **直接点击「本局不再提示」**（仅回合确认窗） | 快捷切换「本局不再提示」勾选状态并将焦点保持在「确认」；`ESC` 退出确认窗自动屏蔽并隐藏该提示 |

## 七、二选一 / 三选一 / 多人六选一决策弹窗（`MODAL_CHOICE`）

触发更换指令、悬赏决策、三连晋升、盟约增益或策略选择弹窗时，系统零模板自动识别**二选一（`1x2` 横排）**、**单人三选一（`1x3` 横排）**与**多人联机六选一（`2x3` 双排网格，兼容 1~5 张已被队友选走的浅灰卡）**，并在手动锁层至决策弹窗时仍自动同步卡片数量与白条索引，完整适配两段式确认机制：

| 按键 | 功能 | 说明 |
| :--- | :--- | :--- |
| **`左摇杆 / D-Pad`** | 选卡导航（自动适配 `1x2` / `1x3` / `2x3`） | 二选一与三选一左右循环切换；多人六选一支持**左右同行循环、上下跨排切换**（`LB/RB` 顺序切换） |

| **`LT`（按住不放）** | **点击右侧「收起」临时查看战场** | 按下 `LT` 自动点击右侧「收起」按钮（自动区分二/三选一与六选一按钮位置）隐藏弹窗看棋盘，**松开 `LT` 自动点击「展开」恢复弹窗！** |

## 八、`LT` 修饰层：信息速查与多人联机互动（局内全程可用）

在休整期与自动作战期，按住 **`LT`（左扳机）** 即可激活信息与联机速查组合键（组合触发后不会误触发单键动作）：

| 组合键 | 功能 | 对应快捷键 / 说明 |
| :--- | :--- | :--- |
| **`LT + D-Pad 左`** | 展开 / 收起 **盟约容器详情面板** | 点击顶部左侧青色放大镜按钮，查看核心与附加盟约羁绊层数 |
| **`LT + D-Pad 上`** | 查看 **敌方波次信息与出怪路线** | 触发官方快捷键 `W`（或点击顶部右侧黄色放大镜预览出怪路线） |
| **`LT + D-Pad 下`** | 打开 / 关闭左下 **「交流」`2x3` 表情面板** | 自动先收起商店再点击左下「交流」按钮，切入 `EMOTE_PANEL` 表情网格导航（亦可在多人队友栏第 4 槽继续按下跨入） |
| **`LT + D-Pad 右`** | 循环切换查看 **联机队友 1~4 棋盘视角** | 顺序切换 1 / 2 / 3 / 4 号队友战场（按 `B` 点击左上延迟安全区退出队友抽屉） |
| **`LT + A / B / X / Y`** | **直达联机队友 1 / 2 / 3 / 4 号位** | 分别对应队友 1（`A`）、队友 2（`B`）、队友 3（`X`）、队友 4（`Y`），按 `B` 一键关闭 |
| **`LT + RT`** | **一键点击右侧本局策略头像** | 不限按压先后顺序，自动适配休整期（右上中）与作战期（右下费用栏上方）双态策略坐标 |

| **`LT + Start`** | 打开左上角 **暂停 / 设置菜单** | 单人模式随时暂停思考，或查看对局设置与退出 |

### 左下「交流」`2x3` 表情面板操作（`FocusZone.EMOTE_PANEL`）

打开左下角「交流」表情面板后，系统自动识别并切换至 `2x3` 表情网格焦点（面板活跃期间自动锁焦防误切棋盘，屏蔽 `LS` 误按）：
- **`左摇杆 / D-Pad`**：在 `2x3` 六枚表情间上下跨排、左右循环切换（指针实时跟随当前表情）；
- **`RS`（右摇杆上下或左右推）或 `LB / RB`**：自动将鼠标悬停至表情面板中心并发送鼠标滚轮，流畅上下/左右翻页查看多页表情（含非青绿与稀疏末页，绝不误跳棋盘）；
- **`A`**：点击发送当前高亮表情；
- **`B`（或再按 `LT + D-Pad 下`）**：点击左下「交流」按钮显式关闭表情面板，自动回归原操作分区。

## 九、自动作战期（`BATTLE_COMBAT`）

- 作战期间仍可通过 **`LT` 组合键** 随时查看本局盟约、敌方波次、切换联机队友视角或发送互动表情；

## 十、个性化手感微调指南

**推荐方式（可视化实时调校）**：直接打开 **纯白极简 PRTS 桌面主控台**（单击/双击系统托盘白底琥珀点图标唤出），点击顶部水平导航 **`调校`** 分区：
- 可视化拖动滑块微调 **左/右摇杆死区、自由光标最大移速、响应曲线指数 `gamma`、滚轮灵敏度、长按开战防误触时长与扳机触发阈值**，同步查看实时响应曲线并在 **`总览`** 靶盘实测手柄输入；
- 点击白底细边 **「应用并持久化保存」** 按钮即自动写入 `configs/user_override.json` 并热刷新生效，也可随时点击 **「恢复默认手感」** 一键还原；同时可在 **`键位`** 分区随时查阅带矢量手柄图示的全流程操作速查卡片。

**进阶手动方式**：如需直接编辑配置文件，可在 `configs/user_override.json` 中覆写以下常用参数（保存后在主控台或托盘点击 **「重新加载配置文件」** 立即生效）：

```json
{
  "keymap": {
    "left_deadzone": 0.14,
    "right_deadzone": 0.16,
    "cursor_max_speed_px": 1400.0,
    "cursor_gamma": 2.2,
    "ready_hold_ms": 350,
    "use_native_keyboard_shortcuts": true,
    "vibration_enabled": true,
    "allow_retreat_chord": true,
    "hide_hud_from_capture": true
  }
}
```

- **希望录屏 / 直播 / 屏幕共享时让观众看到透明 HUD**：在主控台「总览」或托盘菜单取消勾选 **「截屏/共享时隐藏 HUD」**（或将 `"hide_hud_from_capture"` 设为 `false`），立即热切换至 `WDA_NONE` 且不影响局内视觉识别。

- **希望单击 `Start` 立即开战**：将 `"ready_hold_ms"` 调小（如 `0` 或 `120`）。
- **觉得摇杆微调太快或太慢**：适当调高 `"cursor_gamma"`（如 `2.5` 更易微调）或调整 `"cursor_max_speed_px"`。
- **使用未配键的安卓模拟器**：将 `"use_native_keyboard_shortcuts"` 设为 `false`，或在系统托盘右键直接取消勾选「官方 PC 原生快捷键模式」。
